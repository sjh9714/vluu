# photos-src — 원본 사진 놓는 곳

여기 있는 이미지 파일은 **git에 커밋되지 않는다** (`.gitignore` 참조).
빌드 파이프라인(`pnpm ingest`)이 읽어서 `public/media/**` 에 최적화 파생물을 만들고, 그 파생물만 커밋된다.

원본은 이 폴더 + 별도 백업(외장/클라우드)에만 존재한다는 뜻이니, **여기 있는 게 유일본이 되지 않게** 주의.

```
photos-src/
├── iphone-15-pro/     ← 아이폰 15 Pro로 찍은 사진
└── nikon-z50ii/       ← 니콘 Z50II로 찍은 사진 (나중에)
```

폴더 이름이 곧 카메라 구분값이 된다. 사이트의 카메라별 전환 필터가 이 폴더를 기준으로 동작한다.

## 내보내는 법 (macOS 사진 앱)

EXIF(촬영일시·렌즈·초점거리·조리개·셔터·ISO·GPS)가 살아있어야 한다.
Sanity에 올라가 있던 기존 사진들은 EXIF가 전부 지워진 상태라 촬영정보를 하나도 쓸 수 없었다.

### A. 미편집 원본 내보내기 — 권장

```
파일 > 내보내기 > N개의 미편집 원본 내보내기...
```

찍힌 그대로(HEIC 또는 JPEG)를 무손실로 꺼낸다. EXIF·GPS 완전 보존.
HEIC는 파이프라인이 `sips`로 알아서 변환하니 그대로 두면 된다.

### B. JPEG로 내보내기

```
파일 > 내보내기 > N장의 사진 내보내기...
  사진 종류      JPEG
  품질          최고
  색상 프로파일  원본
  ☑ 위치 정보 포함        ← 체크 안 하면 GPS가 날아간다
  하위 폴더 형식  없음
  파일 이름      파일 이름 사용
```

### 파일명

원본 파일명 그대로 두는 게 좋다. 촬영 순서 파악에 쓴다.
(`IMG_1234.HEIC`, `DSC_0042.JPG` 같은 형태)

## 넣고 나면

사진을 넣은 뒤 알려주면:

1. 컨택트시트로 전체를 훑고
2. 잡아둔 콘셉트(ATLAS / TRANSIT / VIEWER, 하드 화이트 큐브)가 새 셀렉에도 맞는지 확인한 뒤
3. Phase 0 (레포 초기화) 부터 진행한다.
